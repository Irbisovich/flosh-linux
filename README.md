# flosh-linux

*Flosh Linux* is a minimalistic *Linux* distro, running as *LiveCD*. It uses it's own *init* script and has a *flosh* utility for packages and system management.
Currently avaliable for *32-bit* (*x86*) machines with *Legacy BIOS* and *64-bit* (*x86-64/amd64*) machines with *UEFI*.

###### P. S. This distro is in testing, can be buggy
